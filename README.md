# Reeta-salon

Reeta-salon is deployed as a static website with GitHub Pages.

## Free hosted URL

After Pages is enabled for this repository, the free hosted URL is:

`https://rajasuna.github.io/Reeta-salon/`

GitHub Pages is available at no hosting cost for public repositories. This repository is not being deployed automatically; repository owner setup is required.

## Enable GitHub Pages

1. Open the repository on GitHub and go to **Settings > Pages**.
2. Under **Build and deployment**, select **GitHub Actions** as the source.
3. Push to the `main` branch and use the **Deploy GitHub Pages** workflow.

No account creation, domain registration, DNS change, or paid service is required for the free `.github.io` subdomain.
